🚀 Проекты
📬 Mail to Telegram Bot — живой продукт с пользователями и оплатой
Telegram-бот, который за 5–15 секунд пересылает новые письма из Mail.ru, Gmail, Яндекса и любой IMAP-почты в Telegram. Сделал в одиночку: от кода до продакшена на VPS. Работает как @FromMailBot.
Kotlin, Ktor, корутины: IMAP IDLE с одним постоянным соединением на ящик вместо входа каждые 15 секунд
Надежная доставка: очередь-outbox в SQLite с повторами, ничего не теряется при сбоях Telegram
Безопасность: пароли ящиков шифруются AES-256-GCM, проверка подписи Telegram initData, защита от SSRF
Монетизация: подписки Pro и Business за Telegram Stars, пробный период, реферальная программа
Mini App на React + TypeScript: подключение ящиков, фильтры, просмотр писем с поиском
Инфраструктура: Docker Compose, Caddy с HTTPS, ежедневные бэкапы, мониторинг `/health`
`Kotlin` `Ktor` `Coroutines` `SQLite` `Jakarta Mail` `React` `TypeScript` `Docker`
🏢 Корпоративный портал — командный проект, бэкенд и база данных
Портал компании: новости, бронирование переговорок, календарь, заявки на услуги, техподдержка и документы с разграничением ролей. Моя часть — проектирование базы данных и бэкенд.
`Java 17` `Spring Boot 3` `Spring Security` `JWT` `JPA / Hibernate` `PostgreSQL`
🎵 Playlist Maker — Android-приложение
Поиск музыки через iTunes API, плейлисты, избранное и история поиска. Учебный проект Яндекс Практикума, выполнен самостоятельно.
`Kotlin` `Jetpack Compose` `MVVM` `Coroutines / Flow` `Room` `Retrofit` `DataStore`
